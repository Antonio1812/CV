Proiect principal

PracticePal

Aplicatie software pentru administrarea stagiilor de practica

Am construit o aplicatie orientata pe roluri, prin care studentii, companiile si administratorii facultatii pot gestiona intregul flux de practica: creare cont, aprobare companii, publicare posturi, aplicare, evaluare, notare finala si raportare.

  • Am lucrat pe o arhitectura Java 21 + Jakarta EE, cu Servlets, JSP, JPA si MySQL, organizata pe straturi clare pentru prezentare, logica de business si persistenta.
  • Am integrat functionalitati utile intr-un context real: profil student cu CV si fotografie, moderare joburi, import/export Excel, chat intern prin WebSocket si dashboard separat pentru fiecare rol.
  • Proiectul m-a ajutat sa inteleg mai bine separarea responsabilitatilor in cod, validarea datelor, securizarea fluxurilor si modelarea regulilor de business intr-un sistem mai amplu.
Java 21 Jakarta EE Servlets & JSP JPA MySQL Gradle WebSocket
Aplicatie software

SportMatch

Platforma pentru organizarea meciurilor amicale intre jucatori

Am dezvoltat o aplicatie in PHP si MySQL care ajuta utilizatorii sa gaseasca rapid parteneri de joc si sa organizeze meciuri amicale pe mai multe sporturi, intr-un flux mai clar decat grupurile clasice de mesagerie.

  • Aplicatia acopera 9 sporturi si include camere de joc, cereri de inscriere, accept/reject, chat, notificari, profil public si feedback intre jucatori.
  • Am lucrat la logica de business pentru gestionarea locurilor, restrictionarea conflictelor intre camere, arhivarea meciurilor, istoricul participarilor si consistenta datelor.
  • Am folosit JavaScript vanilla, Google Maps API si validari de securitate de baza precum parole hash, token CSRF, prepared statements si controlul sesiunii.
PHP MySQL Vanilla JS HTML & CSS Google Maps API CSRF & auth
